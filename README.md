# Бот для клопотань

Telegram-бот, який збирає дані через покроковий діалог і генерує готові клопотання у форматі `.docx` (Times New Roman 14, шапка адресата праворуч, підписи профкому та Колегії студентів). Підтримує додавання кількох клопотань в один документ і перевірку вже готових `.docx`.

## Запуск

### Через `uv`

```bash
uv sync
export BOT_TOKEN="токен від @BotFather"
uv run bot
```

### Через `pip`

```bash
pip install -r requirements.txt
export BOT_TOKEN="токен від @BotFather"
python bot.py
```

Токен також можна покласти у `.env` (див. `env.example`).

## Типи клопотань

- Приміщення, зала, укриття, коридор або аудиторія (разово чи на семестр).
- Спортивна зала, поле, інвентар або Народний дім «Просвіта».
- Розміщення на території, в'їзд машин або вхід у вихідні та на репетиції.
- Звуковий супровід, техніка, автобус, друк матеріалів або закупівля з таблицею в додатку.
- Поселення в гостьову кімнату, використання робочої кімнати чи помісячна оплата гуртожитку.
- Звільнення студентів від пар (список у тексті або в додатку), преміювання студентів та довільний текст.

Формат дат: `16.09.2026`, `17-18.10.2026`, `19.04, 26.04, 03.05.2026` (можна з годинами на кшталт `26.11.2026 16:00-20:30`). Щоб вставити довільний рядок дати чи часу без розбору, поставте `!` на початку.

## Структура та конфігурація

| Призначення | Шлях |
|---|---|
| Список адмінів, які отримують копії `.docx` | `data/admins.json` (або команда `/admins`) |
| Університет, підписанти та адресати | `data/officials.json` |
| Інститути, директори та склад профбюро | `data/institutes.json` |
| Перелік відповідальних за категоріями | `data/responsibles.json` |
| Списки приміщень, корпусів і техніки | `data/places.json` |
| Шаблони та кроки діалогу | `app/core/templates.py` |
| Очищення та нормалізація тексту | `app/core/cleaners.py` |
| Побудова `.docx` (шрифт, відступи, таблиці) | `app/docx/builder.py` |
| Перевірка чернеток і готових `.docx` | `app/docx/validator.py` |
